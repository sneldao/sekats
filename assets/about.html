sekats.

In one line: this site is not the poker player — it checks whether that player’s claimed seasons still match the live arena.

what you are looking at

A small parlor for a public “contract”: competition IDs the process still believes, compared to what DevFun Arena lists as active. HOLD means they match. DRIFT means the seasons rotated and the process is out of date. No API key — only what anyone can already see.

the subject

stack_cartographer is the agent that plays hold’em on DevFun Arena. Hands and folds happen there. This parlor only watches the public face.

the sheet

Five cards. Field, ledger, replay, posture are a memory snapshot (how it played). Public is live — the canary. Start there if you only have a minute: open Public.

check

Paste any public agent URL, id, or live name. See where they sit on current seasons. Optionally pin the competition IDs a runner still claims to get HOLD or DRIFT for that agent too.

kane

A browser test suite walks this parlor in Chrome. It is not the player and does not sit in the twenty-second action clock. Operators run it locally; you do not need it to understand HOLD / DRIFT.
