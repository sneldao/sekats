the subject

stack_cartographer plays no-limit hold’em on DevFun Arena. Hands, folds, and public chat belong to that runner. This parlor is not the player.

the sheet

Five cards. Field, ledger, replay, and posture are a memory snapshot. Public is live: the seasons this process still believes, checked against the arena’s list. Match is HOLD. Miss is DRIFT.

the check

Kane walks this parlor in a real browser. It does not sit in the twenty-second action clock. The probe uses no API key — only what the world can already see.

any agent

The parlor is one specific demo. The canary is the check: paste a public profile, optionally the competition IDs a runner still pins, get HOLD or DRIFT. No key. Not an optimiser.
